# Algoritmos y Estructuras de Datos

Este repositorio contiene la implementación, ejercicios y proyectos desarrollados durante el curso de **Algoritmos y Estructuras de Datos**. El objetivo principal de la materia es aprender a diseñar, analizar e implementar algoritmos eficientes, así como seleccionar las estructuras de datos adecuadas para resolver problemas computacionales complejos de manera óptima.

---

## Contenido del Curso

### 1. Análisis de Algoritmos
* **Notación Asintótica:** Análisis de complejidad temporal y espacial (Big-O, Big-$\Omega$, Big-$\Theta$).
* **Eficiencia:** Evaluación del rendimiento de algoritmos en el peor, mejor y caso promedio.

### 2. Estructuras de Datos Lineales
* **Arreglos y Listas Enlazadas:** Listas simples, doblemente enlazadas y circulares.
* **Pilas (Stacks) y Colas (Queues):** Implementación (basada en arreglos y punteros) y aplicaciones prácticas (evaluación de expresiones, recorrido BFS).

### 3. Estructuras de Datos No Lineales
* **Árboles:** Árboles binarios, Árboles Binarios de Búsqueda (BST), y árboles balanceados (AVL, Red-Black).
* **Heaps:** Montículos binarios (Min-Heap / Max-Heap) y colas de prioridad.
* **Grafos:** Representación (lista de adyacencia y matriz de adyacencia), recorridos en profundidad (DFS) y anchura (BFS).

### 4. Algoritmos de Búsqueda y Ordenamiento
* **Búsqueda:** Búsqueda lineal, búsqueda binaria.
* **Ordenamiento Elemental:** Bubble Sort, Insertion Sort, Selection Sort.
* **Ordenamiento Eficiente:** Merge Sort, Quick Sort, Heap Sort.

### 5. Tablas Hash
* **Funciones Hash:** Mapeo de claves y dispersión.
* **Resolución de Colisiones:** Encadenamiento (*chaining*) y direccionamiento abierto (*open addressing*).

### 6. Tácticas de Diseño de Algoritmos
* **Recursión y Divide y Vencerás**
* **Algoritmos Devoradores (Greedy)**
* **Programación Dinámica**
